# GovernanceFund 사이트 사용 가이드

> 백테스트 · 페이퍼 트레이딩 · 마켓 사이트 실행·사용법.
> 코드: `governance/` · 최종수정: 2026-06-11

---

## 1. 실행 (서버 2개)

프론트가 Next.js로 재구축되어 **백엔드 + 프론트 2개**를 띄운다.

```bash
# ── 백엔드 (레포 루트에서) ──
pip install -r governance/requirements.txt
python -m uvicorn governance.api.main:app --port 8099
#   → HL WebSocket 라이브 워커 자동 기동, SQLite(governance.db) 자동 생성

# ── 프론트 (별도 터미널) ──
cd governance/web-next
npm install          # 최초 1회
npm run dev          # → http://localhost:3010
#   Next가 /api/* 를 8099 백엔드로 프록시
```

브라우저: **http://localhost:3010**

> Windows 한글 깨짐: `set PYTHONIOENCODING=utf-8` 후 백엔드 실행.
> (구버전 정적 프론트 `governance/web/`도 8099에 남아있으나 대체됨)

## 3. 과거 백테스트 사용법

```
① 펀드 프로파일 선택
     공격적 = T_CONVERGE 7일, 레버리지 5x  (반응 빠름, 변동 큼)
     보수적 = T_CONVERGE 21일, 레버리지 2x (반응 느림, 안정적)

② 기간(90/180일) · 투표 주기(매일/3일/주간) 선택

③ [백테스트 실행 ▶]

④ 결과 해석
   - 수익률 곡선: 시나리오 4종 vs Buy&Hold(흰 점선)
   - 성과 지표 표: 누적/연환산/Sharpe/최대낙폭/승률/청산
   - 종목 차트: 코인 버튼 클릭 → HL 실제 캔들
```

### 시나리오 의미
| 시나리오 | 투표 방식 |
|----------|-----------|
| 모멘텀 | 최근 오른 코인 롱 (추세 추종) |
| 역추세 | 최근 오른 코인 숏 (역방향) |
| 랜덤 | 무작위 투표 |
| 완벽예측 | 미래를 알고 투표 (이론적 상한) |

### 꼭 알아둘 것
> **Perfect(완벽예측)가 압도적으로 이기는 게 정상.**
> 이는 "투표가 정확하면 수익이 난다"는 메커니즘 검증이다.
> 멍청한 전략(랜덤 등)이 손실 나는 것도 정상 — 시스템은 투표를 충실히 반영할 뿐,
> **실제 수익은 참여자의 투표 품질이 결정한다.**

## 4. 라이브 페이퍼 트레이딩 (멀티펀드, 돈 없이 체험)

### 4-1. 펀드 목록
탭: **전체 / Demo / 실제**. 카드에 수익률·펀딩캐리·참여자·유니버스.
내가 만들었거나 참여한 펀드가 상단. 식별은 localStorage 닉네임(인증은 5차).

### 4-2. 펀드 개설 (➕)
```
이름 · 종류(Demo/실제) · 공개범위(Public/Private, Private면 허용지갑 저장)
· 프로파일(공격적5x/보수적2x/현물1x) · 가상예치금 · 최대한도
· 운용 자산 = ⌘K 팔레트로 선택 (크립토/주식/지수/원자재/FX/Pre-IPO, 분류 일괄추가)
  → 투표 부담 방지를 위해 **최대 10종**까지
```

### 4-3. 펀드 상세 (투표·운용)
```
① 가상 예치금
② 💵 현금 보유 비율: 0/10/25/50 또는 직접입력 → 나머지를 종목에 배분
③ 종목별 방향: 강숏(-2)/숏(-1)/유지(0)/롱(+1)/강롱(+2)
④ [투표 제출/갱신]  (예치금 많을수록 표 셈, 가중평균)
```
우측 실시간 반영:
- 펀드 수익률 / 펀딩 캐리(연) / 펀드 자산
- 포트폴리오 표: 자산별 비중·수익률·펀딩·평단·**청산가(절대가격)** + **CASH 행**
  · 자산명 옆 결제통화·유효레버 뱃지 (예: USDC·5x, OPENAI는 USDH·3x)
  · 유효레버 = min(펀드레버, 자산 최대레버) — 자산 한도 존중
- 실시간 NAV (분 단위, UTC), 리더보드

### NAV / 라이브 / 시간대
- 마켓 시세·모달 캔들 마지막 봉 = HL WebSocket 실시간(가격 깜빡임).
- 펀드 NAV = 라이브 가격 mark-to-market, 분 단위 SQLite 영속.
- **차트 시간축은 UTC** (한국시간 KST와 9시간 차이).

### 세션 초기화
[세션 초기화] → 해당 펀드 투표/NAV 리셋.

## 5. 마켓 탭

- 카테고리(크립토/TradFi/Pre-IPO) · 검색 · 정렬(거래량/24h/펀딩/가격) · 즐겨찾기(★)
- 타일: 라이브 가격(플래시) + 스파크라인(스크롤 시 lazy 로드)
- 타일 클릭 → **상세 모달**: 캔들(OHLC 호버·휠 줌·봉 롤오버) + 펀딩비 추이 + 상대가격
- ⌘K: 빠른 검색 팔레트

## 6. API (직접 호출용)

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/api/config` · `/api/scenarios` | 메타 |
| GET | `/api/prices/{sym}` · `/api/funding/{sym}` · `/api/relative?a=&b=` | 차트(HIP-3 prefix 지원) |
| GET | `/api/assets` · `/api/spark/{sym}` · POST `/api/sparks` | 자산 레지스트리/스파크 |
| GET | `/api/live` · WS `/ws/market` | 라이브 가격 |
| POST | `/api/backtest` | 시나리오 백테스트(+ custom_votes) |
| POST/GET/DELETE | `/api/funds` · `/api/funds/{id}` | 멀티펀드 CRUD |
| POST | `/api/funds/{id}/vote` · GET `/state` · POST `/reset` | 펀드별 운용(현금투표 포함) |
