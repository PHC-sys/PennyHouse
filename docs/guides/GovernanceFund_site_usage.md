## 1. 실행

레포 루트(`D:\DeFi\PennyHouse`)에서:

```bash
# 1) 의존성 설치 (최초 1회)
pip install -r governance/requirements.txt

# 2) (선택) 엔진 검증 — assert 전부 통과하는지 확인
python governance/tests/test_engine.py

# 3) 서버 실행
python -m uvicorn governance.api.main:app --port 8099
```

브라우저에서 접속:
```
http://127.0.0.1:8099
```

서버를 끄려면 터미널에서 `Ctrl + C`.

> Windows에서 한글 출력이 깨지면: `set PYTHONIOENCODING=utf-8` 후 실행.

## 3. 과거 백테스트 사용법

```
① 펀드 프로파일 선택
     공격적 = T_CONVERGE 7일, 레버리지 5x  (반응 빠름, 변동 큼)
     보수적 = T_CONVERGE 21일, 레버리지 2x (반응 느림, 안정적)

② 기간(90/180일) · 투표 주기(매일/3일/주간) 선택

③ [백테스트 실행 ▶]

④ 결과 해석
   - 수익률 곡선: 시나리오 4종 vs Buy&Hold(흰 점선)
   - 성과 지표 표: 누적/연환산/Sharpe/최대낙폭/승률/청산
   - 종목 차트: 코인 버튼 클릭 → HL 실제 캔들
```

### 시나리오 의미
| 시나리오 | 투표 방식 |
|----------|-----------|
| 모멘텀 | 최근 오른 코인 롱 (추세 추종) |
| 역추세 | 최근 오른 코인 숏 (역방향) |
| 랜덤 | 무작위 투표 |
| 완벽예측 | 미래를 알고 투표 (이론적 상한) |

### 꼭 알아둘 것
> **Perfect(완벽예측)가 압도적으로 이기는 게 정상.**
> 이는 "투표가 정확하면 수익이 난다"는 메커니즘 검증이다.
> 멍청한 전략(랜덤 등)이 손실 나는 것도 정상 — 시스템은 투표를 충실히 반영할 뿐,
> **실제 수익은 참여자의 투표 품질이 결정한다.**

## 4. 페이퍼 트레이딩 사용법 (돈 없이 체험)

```
① 닉네임 입력 (예: 부장님)
② 가상 예치금 입력 (예: 10000) — 많이 넣을수록 투표권 셈
③ 펀드 프로파일 선택
④ 코인별 방향 선택:
     강숏(-2) / 숏(-1) / 유지(0) / 롱(+1) / 강롱(+2)
⑤ [투표 제출 / 갱신]
```

제출하면 우측에 실시간 반영:
- **펀드 수익률 / 자산**
- **포트폴리오** (목표 → 현재 비중, 막대 좌=숏·우=롱)
- **실시간 NAV** 곡선
- **리더보드** (참여자별 평가액·수익률)

### 여러 명 시뮬레이션
닉네임을 바꿔가며 여러 번 투표하면 여러 참여자가 생긴다.
→ **예치금 많은 사람의 표가 더 세게 반영**되는 걸 확인할 수 있다.

### NAV가 0%에 가까운 이유
NAV는 HL **현재가 mark-to-market**이라, 짧은 시간엔 가격이 거의 안 변해 0% 근처.
시간이 지나며 실제 가격 변동이 누적된다. (빠른 데모용 "과거 리플레이" 모드는 추후 추가 예정)

### 세션 초기화
[세션 초기화] 버튼 → 모든 참여자/포지션 리셋.

## 5. API (직접 호출용)

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/api/config` | 코인·프로파일 메타 |
| GET | `/api/prices/{coin}?days=90` | HL 캔들 |
| POST | `/api/backtest` | 시나리오 백테스트 |
| POST | `/api/paper/vote` | 페이퍼 투표 제출 |
| GET | `/api/paper/state` | 펀드 현황+NAV |
| POST | `/api/paper/reset` | 세션 초기화 |

예) 백테스트:
```bash
curl -X POST http://127.0.0.1:8099/api/backtest \
  -H "Content-Type: application/json" \
  -d '{"profile":"aggressive","days":180,"rebalance_every":7}'
```
