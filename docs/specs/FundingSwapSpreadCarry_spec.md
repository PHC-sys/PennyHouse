---

## 0. 한 줄 요약
경제적으로 유사한 두 자산의 **펀딩비 괴리(스프레드)**를 perp-only 롱/숏으로 수확하는
**방향 무관 상대가치 캐리** 전략. 펀딩 = 베이시스(프리미엄) = "크립토 채권의 금리"이며,
캐리 수취와 베이시스 수렴(가격손익)은 같은 프리미엄의 두 장부다.

---

## 1. 기존 대비 무엇이 다른가
| | 고전 델타뉴트럴 캐리 | **FSSC** |
|---|---|---|
| 구조 | 동일자산 Spot Long + Perp Short | **서로 다른 유사자산** Perp Long/Short |
| 레버리지 | Spot 무레버리지 → 캐리 상한 ~연 11% | **양 레그 레버리지** → 캐리 상한 돌파 |
| 헷지 | 완전(동일자산) | **경제적 유사성**(ETF↔구성종목, 인덱스↔대형주) |
| 방향 | 고정(숏 베이시스) | **부호 무관, 스프레드 따라 스위칭** |

핵심 전환: ① 기초자산을 달리한다 ② perp만으로 롱/숏 구성.
제약: ① 명확한 상관·유사성 페어만 ② **충분한 유동성** 종목만.

---

## 2. 핵심 통찰 — 펀딩 = 베이시스 = 채권
- 펀딩비는 **레버리지 수요의 가격** = perp의 index 대비 프리미엄(베이시스).
- 숏-perp 총수익 = (받은 펀딩) + (진입 베이시스 − 청산 베이시스).
- 프리미엄 유지 → 펀딩 수취 / 프리미엄 수렴 → 가격손익.
  **= 채권: 고금리(캐리) + 금리하락 시 자본이득.** (단, 금리 상승=자본손실도 대칭)
- 관측: 양의 캐리가 역전되며 포지션 PNL로 전환 (채권 Capital Gain과 동형).
- 관측(추가검증): 전환비율 ≈ 시작 캐리의 일환산(연 400%→일 ~1.1%). ※ 며칠 관측,
  과적합 가능 — 전방위 엣지로 신뢰 금지.

## 3. 방향 무관 스위칭 (이 전략의 강점)
펀딩 부호가 어떻게 나오든 **캐리 받는 쪽에 선다**(고펀딩 레그 숏, 저/음펀딩 레그 롱).
- 유지되면 → 펀딩 수취
- 역전되면 → 베이시스 수렴 = 평가이익
→ "어느 방향이든 하나는 나온다." (단 §6의 경로·비용 리스크가 이 강점의 대가)

---

## 4. 논리 전개 (발견자 서술)
1. A 펀딩(f1) 양으로 높다 = 시장 A 롱 강함 → A 숏쳐 캐리.
2. B 펀딩(f2) 음으로 높다 = 시장 B 숏 강함 → B 롱쳐 캐리.
3. 합산 + 레버리지 = 압도적 캐리.
4. 역캐리 전환: f1↓ = A 롱 약화 = A relative short(가격↓) → 내 숏에 +MTM.
5. 역캐리 전환: f2↑(음 약화) = B 숏 약화 = B relative long(가격↑) → 내 롱에 +MTM.
6. 4·5가 포지션 MTM을 +로 키움.
7. ∴ 펀딩 캐리 ⇄ 포지션 평가손익 (동전의 양면).
8. 부호가 위와 반대로 나오면 롱/숏을 반대로 잡으면 됨 (스위칭).

## 6. 리스크 (가설을 죽일 수 있는 것들 — 백테스트 합격 기준)
1. **용량(capacity)**: 거래량≠용량. OI·호가깊이·"내 사이즈가 펀딩을 뒤집는가"로 측정.
   페어1은 OI $20~116M → 수 $M 포지션 현실적(추정). 죽은 페어는 사실상 0.
2. **양날의 베이시스 (확대 구간)**: 숏친 레그 프리미엄이 *더* 벌어지면 캐리 받는 중에도
   MTM 손실. 레버리지 위에서 **수렴 전 청산** 가능. EV + ≠ 생존(경로 리스크).
   캐리=저분산 물방울, 베이시스=고분산 점프. 레버리지가 이 둘을 가른다.
3. **dirty 헷지 (잔여 리스크)**: ETF/인덱스 헷지는 공통팩터만 제거. 분산(종목 고유),
   가중치(나머지 구성), 구조(HIP-3가 진짜 ETF인지/오라클 방식) 리스크 잔존.
   1:1 노셔널 아닌 **베타가중 헷지비율**(시변) 필요.
4. **휩쏘 / 스위칭 비용**: 한 번 플립 = 4체결 × 노셔널 × (수수료+슬리피지).
   스프레드가 choppy하면 양방향 수수료 출혈. **플립 규칙(밴드/히스테리시스)이 곧 알파.**
5. **비용**: HL 수수료 + **빌더덱스(HIP-3) 빌더 수수료 별도 가능** + 펀딩 정산주기.
   "수수료 이상"이 *순(net)*으로 참인지 모델 필요. 유동 페어는 스프레드 작아 더 민감.
6. **펀딩 산식 검증**: 빌더덱스별 펀딩 공식/캡이 다를 수 있음 → 70~165% 산출 근거 확인.

---

## 7. 전통 금융 매핑
- **Swap Spread Carry / Bond RV**: 두 유사 금리상품의 스프레드 캐리 + 수렴.
- Crypto Arbitrage ≈ Crypto Bond Swap. 펀딩 = 크립토 금리.
- FSSC = "유사자산 펀딩 스프레드를 레버리지로 수확하는 RV 캐리."

## 8. 검증 설계 (백테스트 하니스 — 다음 작업)
입력 데이터는 이미 보유: 레그별 펀딩 히스토리·캔들·거래량·OI.
페어1(SKHX+SMSN vs DRAM)부터:
1. 펀딩 스프레드 시계열 + 헷지 회귀(베타, R²).
2. **베타가중** 롱/숏 시뮬 → 펀딩(정산 정확, 부호 반영) + 가격손익 적립.
3. 총수익을 **[캐리] + [베이시스 수렴] + [잔여/고유]** 로 분해.
4. **플립 규칙(히스테리시스) 시뮬 → 휩쏘 비용 차감 후 순손익.**
5. **확대 구간 최대낙폭 + 청산거리**(경로 생존), 레버리지별 스윕.
6. OI 기반 **용량 추정**(엣지 소멸 사이즈 선).
합격 기준: 방향 무관 캐리가 *휩쏘·확대구간·비용을 다 이기고 net + 이며 청산 안 당함*.

## 9. 미해결 질문
- "400% 캐리"의 정체: (a)어느 레그 (b)펀딩인지 가격인지 (c)어느 방향 — 시계열로 핀.
- 전환비율 ≈ 일환산 캐리(관측 ⑧)가 통계적으로 유의한가, 우연인가.
- 최적 플립 규칙 / 헷지비율 추정 / 재밸런싱 주기.
- 페어 발굴 자동화: 유사도 높고 유동성 충분한 페어를 어떻게 스캔할까.
