# PennyHouse — 레버리지 예측시장 구조 설계

> 작성일: 2026-06-01  
> 컨셉: 온체인 레버리지 예측시장 / KI-KO 구조 적용 / AMM 기반

---

## 개요

베트맨 1.3배 배당 이벤트를 PennyHouse에서 3.5배로 제공.  
LP가 마켓메이커 역할을 하며 스프레드를 수취하고,  
유저는 소액 증거금으로 레버리지 베팅, 플랫폼은 수수료를 가져가는 3자 생태계.

---

## 핵심 메커니즘

### YES/NO 토큰 + 레버리지 = KI/KO 구조

```
YES 토큰 가격 = 0.1 (이벤트 발생 확률 10%)
레버리지 10배 적용

KO 배리어: YES 토큰 가격이 청산선 터치 시 증거금 강제청산
KI 배리어: 이벤트 발생(결과 확정) 시 페이오프 수령
```

- YES 토큰 자체 = 디지털 옵션 (0 or 1 페이오프)
- 레버리지 적용 = 이중 배리어 디지털 옵션
- 구조적으로 TradFi 배리어 옵션과 동일

### 배당 스프레드 구조

```
공정 배당 (시장 확률 기반): 3.9배
유저 수령 배당:             3.5배
LP 스프레드 수익:           0.4배 (항상 발생)
```

유저가 이기든 지든 LP는 스프레드를 수취. 손실 시 완충재 역할도 함.

### 레버리지 배당 커브: ln(x+1) 모델

퍼페추얼처럼 선형 레버리지가 아니라, 로그 함수를 따르는 비선형 구조로 설계.

```
공정 배당 (선형):  y = x
유저 수령 배당:    y = ln(x+1)
LP 스프레드:       y = x - ln(x+1)
```

| 레버리지 (x) | 유저 배당 ln(x+1) | LP 스프레드 x - ln(x+1) | LP 비율 |
|---|---|---|---|
| 1배 | 0.69 | 0.31 | 31% |
| 2배 | 1.10 | 0.90 | 45% |
| 3배 | 1.39 | 1.61 | 54% |
| 5배 | 1.79 | 3.21 | 64% |
| 10배 | 2.40 | 7.60 | 76% |

**왜 이 커브인가**

- 레버리지가 커질수록 유저 페이오프 증가율이 자동으로 둔화
- LP 스프레드는 볼록하게(convex) 증가 → 고레버리지 리스크를 자동 프라이싱
- x=0 근방에서 기울기 ≈ 1 → 소액/저레버리지 구간에서 유저에게 거의 공정한 배당
- **별도의 동적 수수료 로직 없이 수식 자체가 리스크 프리미엄을 내장**

**퍼페추얼과의 차이**

퍼페추얼은 레버리지가 선형(y=x)이라 LP가 리스크를 그대로 떠안고, 펀딩레이트로 별도 보정이 필요함. PennyHouse는 커브 자체에 리스크 프리미엄이 내장되어 있어 추가 보정 메커니즘 불필요.

**구현 단순성**

컨트랙트에 ln(x+1) 커브 하나만 박아넣으면 자기 조정(self-regulating) 스프레드 구조 완성.

## 1. LP (유동성 공급자)

### 역할
- 유저의 레버리지 포지션에 마진을 대주는 카운터파티
- 단순 하우스가 아닌 **온체인 마켓메이커**

### 수익 구조

| 수익원 | 발생 조건 | 성격 |
|---|---|---|
| 스프레드 (예: 0.4배) | 항상 발생 | 확정 수익 |
| 하우스 엣지 | 유저가 질 때 | 확률적 수익 |
| 청산 수수료 | 유저 증거금 청산 시 | 조건부 수익 |
| 쏠림 페널티 수수료 | 한쪽 베팅 편중 시 | 리스크 보상 |

### 기대 수익률
- 스프레드 + 하우스 엣지 + 청산 수수료 합산 시 이벤트당 **15~25%** 가능
- 이벤트 다양성 확보 시 수익이 평균으로 수렴 → 안정성 증가

### 리스크
- **갭 리스크**: 주전 부상 등 돌발 뉴스 → 가격 급락 → 청산 전 손실 확정
- **편중 리스크**: 한쪽 베팅 압도적 쏠림 → LP 단방향 노출
- **단일 이벤트 리스크**: 이벤트 수 적을수록 분산 불가

### 리스크 완화 장치
- 이벤트 직전 거래 중단 구간 (예: 킥오프 1시간 전 신규 포지션 불가)
- 동적 배당률 자동 조정 (쏠림 발생 시 배당률 자동 하락)
- LP 최대 노출 한도 설정
- 이벤트 다양화 (스포츠 + 주식 + 크립토 혼합)

### LP 유인 설계
- 플랫폼 토큰 추가 리워드
- 수수료 쉐어 (플랫폼 수수료 일부 LP 분배)
- 초기: 플랫폼이 직접 시드 유동성 공급 → 수익 데이터 축적 → 외부 LP 모집

## 2. 유저 (베터)

### 포지션 구조 예시

```
이벤트: 챔스 결승 약팀 우승
베트맨 배당: 1.3배
PennyHouse 배당: 3.5배 (레버리지 3.5x)

유저 증거금: $10
오픈 포지션: $35
LP가 커버: $25

시나리오 A - 약팀 우승 (KI 발생):
→ 유저 수령: $35 (증거금 $10 → $35, 수익 $25)

시나리오 B - 강팀 우승 (포지션 만기 소멸):
→ 유저 손실: 증거금 $10

시나리오 C - 이벤트 전 확률 급락 (KO 발생):
→ 청산선 터치 → 증거금 강제청산
→ 남은 증거금 LP/플랫폼 귀속
```

### 유저 유인
- 베트맨 대비 최대 3.5배 높은 배당
- 소액 증거금으로 대형 포지션 (자본 효율)
- "적게 넣고 크게 먹는다" — 직관적 UX
- Private 마켓: 친구들끼리 링크 공유로 P2P 베팅

### 유저 리스크
- 레버리지 배수만큼 청산 리스크 증가
- 이벤트 전 청산 가능성 (갭 리스크 노출)
- AMM 슬리피지

### 청산 메커니즘
- 가격 실시간 오라클 (TWAP 방식으로 조작 방어)
- 청산선 터치 시 자동 실행 (청산 봇 + 봇 인센티브)
- 플래시론 방어: 동일 블록 내 청산 불가

---

## 3. 플랫폼 (PennyHouse)

### 역할
- 스마트컨트랙트 배포 및 AMM 운영
- 마켓 큐레이션 (플랫폼) + 마켓 생성 (유저)
- 오라클 연동 및 결과 판정

### 수익 구조

| 수익원 | 내용 |
|---|---|
| 거래 수수료 | 포지션 오픈/클로즈 시 일정 % |
| 청산 수수료 일부 | 청산 봇과 분배 |
| 마켓 생성 수수료 | 유저 큐레이션 마켓 개설 시 |

### 마켓 구조

**플랫폼 큐레이션**
- 챔스 결승, 프리미어리그, 하이닉스 주가, BTC 가격 등 대중 마켓 직접 운영
- 오라클 연동 명확한 이벤트만 (결과 판정 분쟁 최소화)

**유저 큐레이션 (Public)**
- 누구나 마켓 생성 가능
- 마켓 개설 시 담보 예치 (악용 방지)

**유저 큐레이션 (Private)**
- 초대제 P2P 마켓
- 친구들 소액 내기 → 카카오톡 링크 공유 바이럴
- 기관 간 장외 파생 거래로 확장 가능

### AMM 설계 원칙
- 동적 배당률 자동 조정 (쏠림 페널티 내장)
- Circuit Breaker (단시간 급격한 가격 변동 시 거래 중단)
- TWAP 오라클 (단일 시점 가격 조작 방어)
- 이벤트 직전 거래 중단 구간

### 오라클 전략
| 이벤트 유형 | 오라클 |
|---|---|
| 스포츠 결과 (명확) | Chainlink 분산 오라클 |
| 주가/가격 | Chainlink |
| 애매한 이벤트 | UMA 낙관적 오라클 + 분쟁 메커니즘 |

---

## 생태계 플라이휠

```
유저 유입 (고배당 유인)
        ↓
베팅 볼륨 증가
        ↓
LP 수익률 증가 (스프레드 + 하우스 엣지)
        ↓
LP 유동성 증가
        ↓
더 높은 레버리지 제공 가능
        ↓
더 많은 유저 유입
```

이벤트 다양성이 플라이휠 속도를 결정함.

---

## 리스크 요약

| 리스크 | 심각도 | 해결 방안 |
|---|---|---|
| 갭 리스크 | 높음 | 이벤트 직전 거래 중단 |
| 청산 사냥 | 높음 | 포지션 캡 + Circuit Breaker |
| 플래시론 | 높음 | 동일 블록 청산 불가 |
| LP 편중 | 중간 | 동적 배당률 조정 |
| 오라클 조작 | 중간 | TWAP + 분산 오라클 |
| LP 단일 이벤트 손실 | 중간 | 이벤트 다양화 + 노출 한도 |

---

## MVP 전략

1. **챔스 결승 단일 이벤트**로 시작 (결과 명확, 관심도 높음)
2. 플랫폼이 직접 LP 역할 (시드 유동성)
3. 레버리지 3.5배로 제한 (갭 리스크 최소화)
4. 수익 데이터 축적 → 외부 LP 모집
5. 이벤트 다양화 → 플라이휠 가동

## 기술 스택 (잠정)

- 체인: HyperEVM (HIP-4 인프라 활용)
- 컨트랙트: Solidity (ERC-721 포지션 토큰, AMM 풀, 청산 엔진)
- 오라클: Chainlink (스포츠/가격) + UMA (주관적 이벤트)
- 프론트엔드: 카카오톡 링크 공유 가능한 Private 마켓 UI
- 법인: 홍콩 (규제 방어)
