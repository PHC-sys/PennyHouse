## 2. Hyperliquid 예측시장 현황

### HIP-4 (2026.05 메인넷)
- HyperCore 위에 바이너리 이벤트 컨트랙트를 네이티브 프리미티브로 추가
- Yes/No 아웃컴 토큰을 퍼프/스팟과 **동일한 오더북, 동일한 마진 계정**에서 거래
- 포지션 오픈 수수료 없음 (클로즈/정산 시에만 수수료)
- 마켓 개설: HYPE 100만 개 스테이킹 필요 (permissionless)
- 현재는 가격 기반 마켓만 (BTC daily binary가 첫 마켓)
- Phase 2: 외부 오라클 붙이면 선거/스포츠 같은 주관적 이벤트 가능
- **핵심**: 예측시장 인프라 자체가 아니라 HyperCore의 오더북/마진을 아웃컴 컨트랙트 타입에도 확장한 프리미티브

### Polymarket 최신 동향 (2026.05)
- Nasdaq Private Market과 파트너십 → OpenAI, Anthropic, SpaceX 등 Pre-IPO 예측마켓 런칭
- 2026년 미국 거래량 $390억 돌파
- AI 에이전트가 플랫폼 지갑 활동 30% 이상, 수익률도 인간 압도

## 3. PennyHouse 컨셉

### 포지셔닝
> "누구나 동전만 가지고 와도 놀 수 있는 온체인 예측시장"

- 타겟: 투기적 성향 강한 한국 소액 투자자
- 경쟁 상대: 폴리마켓/HIP-4가 아니라 스포츠토토, 해외 스포츠 베팅앱
- 킬러 마켓: 하이닉스 이번 주 오를까? 손흥민 골 넣을까? 삼성 어닝 서프라이즈?
  → 내가 안다고 느끼는 것에 소액 베팅하는 심리

### 마켓 구조
| 유형 | 설명 |
|---|---|
| 플랫폼 큐레이션 | 주식/스포츠/크립토 대중 마켓 직접 운영 |
| 유저 큐레이션 (Public) | 누구나 마켓 생성 가능 |
| 유저 큐레이션 (Private) | 초대제 — 친구들 놀이터 or 기관 간 OTC |

### Private OTC가 핵심 차별화
- 기존에 Private P2P OTC 예측시장 플랫폼 없음 → **공백**
- 구조: A 담보 락 → B 담보 락 → 이벤트 결과 → 스마트컨트랙트 자동 정산
- UX: "카카오톡 내기의 온체인 버전" — 링크 공유로 바이럴
- 확장: 기관 간 장외 파생 거래 플랫폼으로도 활용 가능

### 경쟁 환경 (2026.05 기준)
- XO Market: 유저 생성 Public 마켓, 시드 $600만, 거래량 $1.5억 — 이미 치고 나감
- Polymarket: Pre-IPO 예측마켓 런칭 완료
- **Private P2P OTC**: 아무도 없음 → 여기가 진입점

## 4. 온보딩 현실 (한국 유저)

### 업비트 → Hyperliquid 경로
- 업비트에 USDT/USDC/USDS 출금 가능 (스테이블 직접 출금 됨)
- 단, 지원 네트워크: USDC는 Ethereum/Solana만, USDT는 Ethereum/Tron/Aptos/Kaia만
- **Arbitrum 출금 없음** → HyperEVM 직접 브릿지 불가
- 현실적 경로: USDC Ethereum 출금 → Hyperliquid 브릿지 (가스비 걸림돌)

### 네트워크 선택 딜레마
| 기준 | 최적 선택 |
|---|---|
| 접근성 | Solana (업비트 직출금) |
| 인프라 | HyperEVM (HIP-4 네이티브) |
| 솔리디티 호환 | HyperEVM (Solana는 Rust, Hyperliquid API 연동 불가) |

→ **결론: HyperEVM에 배포, 한 단계 마찰 감수. Pre-IPO 유인이 강하면 유저가 온다.**

## 5. 오프램프 현실

### 왜 이렇게 어렵나
- 달러 자체가 문제가 아니라 **크립토 거래소에서 온 달러**가 문제
- 은행 AML/KYC: 자금 출처 소명 불가 → 수취 거절 or 계좌 동결
- 한국 특금법: VASP 미신고 법인이 크립토 자금 수취 시 미신고 영업 리스크

### 현실적인 오프램프 구조
```
DeFi 플랫폼 수수료 → 개인 지갑 (USDC/USDT)
→ 바이낸스 P2P or OTC 환전소 → 현금/원화
```
- Crypto.com OTC: $50,000 이상, 은행 계좌 연동 필요 (크립토 친화 은행 전제)
- 두바이 법인 + UAE 크립토 친화 은행 → 현재 가장 현실적인 법인 오프램프
- 신한/케이뱅크 법인계좌로 Crypto.com → 불가 (크립토 출처 자금 수취 거절)

### MVP 전략
**KYB(법인) 아니라 KYC(개인) 접근**
- 개인이 시작한 DeFi 플랫폼 컨셉
- 스마트컨트랙트가 에스크로 → 플랫폼은 코드만 배포
- 수수료 개인 지갑으로 수취 → P2P/환전소로 현금화
- "나는 코드를 짰을 뿐" — Uniswap Labs 규제 방어 논리와 동일
- 커지면 그때 해외 법인 구조 고민

## 6. 메이저 DeFi 성공 요인 분석

### 공통 패턴
> 기존 금융의 특정 문제를 수학/코드로 trustless하게 풀었다

| 플랫폼 | 핵심 혁신 | 해자 강도 |
|---|---|---|
| Uniswap | x*y=k AMM, LP 토큰 | 높음 |
| Curve | StableSwap 공식 + veCRV 토크노믹스 | 높음 |
| Aave | Kink 금리 모델 + 리스크 파라미터 세분화 | 높음 |
| Pendle | PT/YT 원금-이자 분리 (스트립 채권 온체인) | 높음 |
| Hyperliquid | 인프라 수직 통합 (체인 자체를 거래소에 최적화) | 높음 |
| Polymarket | 인센티브 설계 + 내러티브 | 중간 |
| Opensea | 선점 + 네트워크 효과 | 낮아짐 |
| Friend.tech | FOMO | 없음 |

### 수학 없이도 성공 가능하나?
- 가능하지만 해자가 얕아짐
- 폴리마켓: CTF 오픈소스 활용 + UMA 낙관적 오라클(게임이론) + 2024 대선 내러티브
- 수학 없이 터진 플랫폼들은 결국 수학 기반 경쟁자에게 잠식됨

### Uniswap/Curve가 Hyperliquid에 안 죽는 이유
- 서로 다른 레이어: Hyperliquid = CEX 대체 (퍼페추얼), Uniswap/Curve = 온체인 금융 인프라 (현물 교환)
- 롱테일 토큰, 컴포저빌리티, LP 수익화 → Hyperliquid가 대체 불가

## 7. PennyHouse 설계 원칙 (정리)

1. **스마트컨트랙트 에스크로** — 신뢰 문제를 코드로 대체
2. **개인 개발자 포지션** — 규제 방어, KYC 접근
3. **한국 특화 마켓** — 하이닉스, 손흥민, 삼성 등 소액 유저가 아는 것
4. **Private P2P OTC** — 기존 플랫폼 없는 공백 공략
5. **MVP 우선** — 소액 놀이터 → 검증 후 Private OTC 확장
6. **수학적 레이어는 나중에** — 초기엔 내러티브+UX, 그 다음 해자 구축
